# 03: 并行加载设备状态、位置和联系人

**What to build:** 用户打开或切换设备详情时，同时加载设备状态、位置和联系人；单项失败不阻止其他成功数据展示，旧设备请求也不能覆盖新选择设备的页面。

**Blocked by:** 01: 消除通用 token，贯通登录、绑定和设备切换

**Status:** complete

- [x] 状态、位置和联系人请求并行开始，不再按顺序等待。
- [x] 总加载时间接近最慢单项请求的耗时，而不是三项耗时之和。
- [x] 任一请求失败时，其余成功数据仍正常显示，并为失败部分保留安全默认状态。
- [x] 快速切换或重复加载时，旧请求结果不会覆盖当前设备数据。
- [x] 每项请求使用目标 SN 对应的设备访问凭证。
- [x] 自动化测试可控制各请求完成顺序并验证部分失败场景。
- [x] 不增加或修改后端接口。
