# 01: 消除通用 token，贯通登录、绑定和设备切换

**What to build:** 用户登录、绑定设备和切换设备时始终使用职责明确的凭证：用户级操作使用登录凭证，设备数据使用目标设备的设备访问凭证。兼容现有本地数据，升级后用户无需重新登录或重新绑定。

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] 前端状态明确区分 `loginToken`、`boundDevices[].deviceAccessToken` 和 `selectedDeviceSn`，不在新实现中引入含义不明的通用 token。
- [x] 扫码、手动输入和场景码三种入口均使用登录凭证绑定设备。
- [x] 绑定成功后，设备、名称、设备访问凭证和当前选择作为一次完整状态更新保存。
- [x] 选择任意设备后，设备请求取得该设备对应的设备访问凭证，登录凭证不被覆盖。
- [x] 现有设备缓存可自动读取或迁移，用户无需重新绑定。
- [x] `npm test` 可在不启动后端、不打开微信开发者工具时验证上述行为。
- [x] 不修改后端接口、页面外观和现有交互流程。
