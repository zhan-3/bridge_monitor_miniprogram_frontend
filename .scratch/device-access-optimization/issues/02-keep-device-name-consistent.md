# 02: 设备名称在所有页面和重启后保持一致

**What to build:** 用户在设备详情或设置中修改设备名称后，首页、详情、设置和重新启动后都显示同一个名称；名称修改不得影响设备访问凭证。

**Blocked by:** 01: 消除通用 token，贯通登录、绑定和设备切换

**Status:** complete

- [x] 首页、设备详情和设备设置从已绑定设备集读取同一设备名称。
- [x] 详情和设置中的改名入口执行同一个改名行为。
- [x] 修改名称时保留原 SN 和设备访问凭证。
- [x] 重启小程序后仍显示修改后的名称。
- [x] 自动化测试覆盖两个改名入口、跨页面读取和重启恢复。
- [x] 不修改后端接口或页面外观。
