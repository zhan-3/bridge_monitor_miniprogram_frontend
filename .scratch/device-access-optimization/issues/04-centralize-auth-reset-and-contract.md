# 04: 统一认证失效清理并删除旧状态入口

**What to build:** 登录凭证无效或请求返回 401 时，通过同一个行为清理用户认证和已绑定设备状态并返回登录页；完成迁移后，页面不能再直接修改旧全局设备字段或设备缓存。

**Blocked by:** 02: 设备名称在所有页面和重启后保持一致；03: 并行加载设备状态、位置和联系人

**Status:** complete

- [x] 无效凭证和 HTTP 401 通过同一清理行为重置登录凭证、已绑定设备集、当前选择和待绑定 SN。
- [x] HTTP 403 继续保持当前失败行为，不误清空登录或设备状态。
- [x] 页面和通用模块不再直接修改旧的通用 token、设备 token 列表、当前 SN 或已绑定标记。
- [x] 旧存储名称只能由兼容迁移读取，正常运行只写入含义明确的新状态。
- [x] 完整测试覆盖登录、三种绑定入口、多设备轮询、切换、详情、联系人、位置、改名、401、403 和重启恢复。
- [x] 不修改后端接口、页面外观和既有错误提示。
